# Controller for Mobile Devices in C++ (ESP8266 + Servo + Web Server)

Цей проєкт перетворює мікроконтролер **Wemos D1 mini (ESP8266)** на інтелектуальний вебсервер, яким можна зручно керувати з будь-якого мобільного пристрою чи комп'ютера в тій самій мережі Wi-Fi. Система дозволяє віддалено змінювати кут повороту сервопривода за допомогою простих HTTP-запитів.

---

## 🚀 Основні можливості

* **Неблокуюча архітектура (State Machine)**: Керування станами пристрою (`CONNECTING`, `RUNNING`, `FAILED`) за допомогою `millis()`, що запобігає зависанням програми.
* **Захист від зависання мережі (Timeout)**: Якщо плата не може підключитися до роутера протягом 30 секунд, вона автоматично переходить у стан помилки та перезавантажується (`ESP.restart()`).
* **Автоматичне відновлення зв'язку**: У разі втрати сигналу під час роботи система самостійно намагається перепідключитися.
* **Мобільний HTTP REST API**: Керування сервоприводом через браузер смартфона або інші мобільні застосунки за допомогою вебпосилань.

---

## 🛠 Апаратне та програмне забезпечення

* **Мікроконтролер**: Wemos D1 mini (ESP8266)
* **Виконавчий пристрій**: Сервопривід (підключений сигнальним дротом до пін `D7`, живлення має подаватися від окремого стабільного джерела 5V з об'єднаною землею).
* **Середовище розробки**: VS Code + PlatformIO
* **Фреймворк**: Arduino

### Залежності (`platformio.ini`)
Використовуються виключно вбудовані бібліотеки ядра ESP8266:
* `ESP8266WiFi`
* `ESP8266WebServer`
* `Servo` (вбудована підтримка для ESP8266)
